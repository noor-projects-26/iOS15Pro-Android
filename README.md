# iOS15Pro-Android

An open-source Android customization toolkit powered by Termux, inspired by the iPhone 15 Pro experience.

## Project Goals

- Detect Android device compatibility.
- Display device and system information.
- Provide safe customization utilities.
- Create configuration backups and restore them.
- Build modular Android customization features.
- Support devices without requiring root for basic features.

## Requirements

- Android device
- Termux
- Git
- Bash

## Installation

```bash
git clone https://github.com/noor-projects-26/iOS15Pro-Android.git
cd iOS15Pro-Android
bash install.sh
```

## Current Status

Version: 0.1.0

Currently implemented:
- Basic device diagnostics
- Android environment detection
- Configuration backup
- Configuration restore foundation

More customization features are planned.

## Important Limitations

This project does not install Apple's iOS or replace Android.
Some interface customizations may require permissions, ADB,
root access, or additional software. Features will be clearly
documented according to their actual requirements.
